# PIMENTA Estudios · web

Web de una sola página para PIMENTA Estudios (alquiler de estudio fotográfico en Congreso, CABA).

## Qué hay en cada lugar

- `index.html` → todos los textos de la web (tarifas, preguntas, etc.). Buscá `[completar` para ver lo que falta.
- `js/datos.js` → **WhatsApp, Instagram, mail y Calendly**. Se cargan una sola vez acá y aparecen en toda la web.
- `fotos/` → las fotos. Leé `fotos/LEEME.md` para saber qué nombre ponerle a cada una.
- `css/estilos.css` → colores y diseño. Los colores están arriba de todo.
