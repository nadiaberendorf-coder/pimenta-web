# PIMENTA Estudios · web

Web de una sola página para PIMENTA Estudios (alquiler de estudio fotográfico en Congreso, CABA).

## Qué hay en cada lugar

- `js/datos.js` → **lo que más vas a tocar**: WhatsApp, Instagram, mail, Calendly, tour 360°, seña, **precios** y fecha del precio web.
- `index.html` → la página principal (landing corta): portada, tarifas, 360°, eventos, marcas y opiniones, reservar y contacto.
- `estudio.html` → el estudio: espacios, plano, recorrido 360°, la luz y todo lo que incluye.
- `producciones.html` → marcas, galería de producciones y todas las opiniones.
- `eventos.html` → la página de eventos (hasta 100 personas, todo incluido, presupuesto a medida).
- `preguntas.html` → preguntas frecuentes y cómo llegar.
- La barra de arriba y el menú del celular están repetidos en cada página: si cambiás un link, cambialo en las cinco.
- Buscá `[completar` en cualquier página para ver lo que falta.
- `fotos/` → las fotos. Leé `fotos/LEEME.md`.
- `img/` → logo y favicon (el plano va dibujado dentro de `index.html`).
- `css/estilos.css` → colores y diseño. Los colores están arriba de todo.
