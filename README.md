# PIMENTA Estudios · web

Web de una sola página para PIMENTA Estudios (alquiler de estudio fotográfico en Congreso, CABA).

## Qué hay en cada lugar

- `js/datos.js` → **lo que más vas a tocar**: WhatsApp, Instagram, mail, Calendly, tour 360°, seña, **precios** y fecha del precio web.
- `index.html` → la web completa en una sola página (portada, estudio, todo incluido, tarifas, producciones, opiniones, eventos, reservar, preguntas, ubicación y contacto).
- `eventos.html` → la página de eventos (hasta 100 personas, todo incluido, presupuesto a medida). Se abre desde el menú y desde el bloque de eventos.
- La barra de arriba y el menú del celular están repetidos en las dos páginas: si cambiás un link, cambialo en las dos.
- Buscá `[completar` para ver lo que falta.
- `fotos/` → las fotos. Leé `fotos/LEEME.md`.
- `img/` → logo y favicon (el plano va dibujado dentro de `index.html`).
- `css/estilos.css` → colores y diseño. Los colores están arriba de todo.
